# P13 — Choosing Flexbox or Grid

## Aim
Compare CSS Flexbox and CSS Grid in one dashboard. Flexbox is used for the header and toolbar because their items are arranged along one primary axis. Grid is used for the dashboard columns and statistic cards because those layouts require coordinated rows and columns.

## Files
- `index.html`: dashboard structure.
- `styles.css`: Flexbox and Grid layout rules.

## How to run
Open `index.html` in a modern browser and resize the viewport.

## Concepts demonstrated
- Flexbox: header alignment, action buttons, and sidebar navigation.
- Grid: sidebar/content shell and responsive statistic cards.
- Responsive design: the dashboard collapses to one column on smaller screens.
