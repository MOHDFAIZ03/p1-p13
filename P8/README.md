# P8 — Sticky navbar and positioned card overlay

## Aim
A sticky navigation bar and an absolutely positioned badge within a relatively positioned card.

## Files
- `index.html`: semantic page structure and sample content.
- `styles.css`: layout, visual design, and responsive rules.

## How to run
Open `index.html` in a modern browser. No external libraries or build step are required.

## Concepts demonstrated
position: sticky, position: relative, position: absolute, and overlay placement.
