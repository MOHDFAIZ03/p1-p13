# P1 — Project folder and terminal navigation

## Aim
Create a project directory and practice navigating the file system from a terminal.

## Procedure
1. Open Terminal.
2. Display the current directory with `pwd`.
3. List files with `ls -la`.
4. Create a workspace and enter it:
   ```bash
   mkdir -p ~/web-development-lab
   cd ~/web-development-lab
   ```
5. Create the practical directory and files:
   ```bash
   mkdir P1
   cd P1
   touch index.html README.md
   ```
6. Move between directories with `cd ..`, `cd ~`, and `cd -`.
7. Verify the result using `pwd` and `ls -la`.

## Expected result
A workspace containing a P1 directory with the two files. Record terminal commands and their outputs during the lab.
