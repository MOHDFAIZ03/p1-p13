# P12 — Advanced CSS Grid projects layout

## Aim
A responsive project gallery with spanning cards, named grid placement, and auto-fit behavior.

## Files
- `index.html`: semantic page structure and sample content.
- `styles.css`: layout, visual design, and responsive rules.

## How to run
Open `index.html` in a modern browser. No external libraries or build step are required.

## Concepts demonstrated
Grid spans, auto-fit/minmax, varied card placement, and responsive gallery design.
