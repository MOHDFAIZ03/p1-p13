# P7 — CSS design tokens and typography

## Aim
A reusable design system using CSS custom properties for color, spacing, type, and radii.

## Files
- `index.html`: semantic page structure and sample content.
- `styles.css`: layout, visual design, and responsive rules.

## How to run
Open `index.html` in a modern browser. No external libraries or build step are required.

## Concepts demonstrated
CSS custom properties, design tokens, typography scale, and reusable components.
