# P9 — Responsive navbar and card grid with Flexbox

## Aim
A wrapping Flexbox navigation and responsive card row that adapts to narrow screens.

## Files
- `index.html`: semantic page structure and sample content.
- `styles.css`: layout, visual design, and responsive rules.

## How to run
Open `index.html` in a modern browser. No external libraries or build step are required.

## Concepts demonstrated
display: flex, flex-wrap, gap, flexible card sizing, and responsive navigation.
