# P6 — Semantic portfolio structure

## Aim
A complete portfolio page organized with header, navigation, main, sections, article, and footer.

## Files
- `index.html`: semantic page structure and sample content.
- `styles.css`: layout, visual design, and responsive rules.

## How to run
Open `index.html` in a modern browser. No external libraries or build step are required.

## Concepts demonstrated
Header, navigation, main, section, article, footer, and reusable content groups.
