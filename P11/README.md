# P11 — Three-column newspaper layout with Grid

## Aim
An editorial newspaper page using named CSS Grid areas and a responsive single-column breakpoint.

## Files
- `index.html`: semantic page structure and sample content.
- `styles.css`: layout, visual design, and responsive rules.

## How to run
Open `index.html` in a modern browser. No external libraries or build step are required.

## Concepts demonstrated
CSS Grid template areas, column tracks, grid placement, and responsive reflow.
