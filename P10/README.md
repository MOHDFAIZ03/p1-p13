# P10 — Advanced Flexbox header and footer

## Aim
A responsive site shell using Flexbox alignment, spacing, wrapping, and flexible growth.

## Files
- `index.html`: semantic page structure and sample content.
- `styles.css`: layout, visual design, and responsive rules.

## How to run
Open `index.html` in a modern browser. No external libraries or build step are required.

## Concepts demonstrated
Flexbox alignment, justify-content, align-items, flexible spacing, and wrapping.
